# Comet

Comet is a Palm sized desk robot with a Space theme. Its big expressive eyes are drawn on a small OLED screen, and it can blink, look around, get sleepy, and light up when you pet it. A small servo lets it nod and tilt its head, and a touch sensor lets people interact with it at Maker Faire. I’m building it as a beginner, starting with the eyes and the nod, then adding extras like constellation animations, ears, and a little astronaut outfit if time allows.
